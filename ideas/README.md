# ideas/

> **Шаг 1 конвейера.** Сырьё — `../trends/`. Дальше: `../specs/`.
> Путь целиком — `../docs/PLAY.md`.

Вход конвейера. Одна идея — один файл, пишется руками за пятнадцать минут.

```
ideas/gate1.md            правило первых ворот: критерии, шкала, порог
ideas/_TEMPLATE.md        шаблон идеи — восемь разделов
ideas/active/NN-slug.md   идея, оценка и решение Gate 1
ideas/rejected/NN-slug.md не прошла Gate 1 — с одной строкой почему
ideas/validate.mjs        проверка формы и арифметики порога
```

Папка и поле `gate1` в шапке — одно и то же состояние, записанное дважды, и
валидатор падает при расхождении: файл нельзя переложить, забыв поменять
решение. Отказ не удаляется — история отказов не даёт через месяц зайти на
тот же круг.

`NN` — номер концепта, а не день выхода.
