# ideas/

Вход конвейера: `ideas/NN-slug.md`, по файлу на концепт. Шаблон —
`docs/templates/idea.md`, проверка — `node ideas/validate.mjs`.

## Почему папка пустая

Тридцать концептов, которые сейчас лежат в `specs/`, писались до того, как
этап идеи появился. Переписывать их задним числом смысла нет: идея, собранная
из готовой спеки, не выполняет свою работу — она повторяет решения, которые
уже приняты, и kill-критерий в ней оказывается подогнанным под то, что
написали позже.

Поэтому этап начинается с концепта 36 и дальше. Спеки 1–35 остаются как есть.

## Порядок

1. Идея пишется руками: `ideas/NN-slug.md` по шаблону.
2. `node ideas/validate.mjs` — шапка на месте, восемь разделов непусты, слаг
   свободен.
3. AI пишет спеку `specs/NN-<slug>.md`: шапка переезжает без изменений и
   дополняется `pitch_ru`, `pitch_en`, `score`.
4. Слаг попадает в `games.json` на свой день.

Дальше — `docs/pipeline.md`.

## Что здесь не пишется

Уровни, интерфейс, цифры баланса, список событий аналитики. Всё это —
следующий шаг. Идея отвечает на вопрос «что проверяем и когда хороним», а не
«как это собрать».
