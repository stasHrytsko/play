## 2026-09-16 — Форк game-template под 30/30

**Решение:** форкаем game-template- под нужды эксперимента.
- Capacitor/Android убирается из дефолтного пути (npm run cap:sync,
  cap add android больше не часть обычного скрипта), остаётся опционально
  для победителя в фазе 2. capacitor.config.ts остаётся в репозитории.
- levelCount фиксируется на 5 (было 9).
- Сигнал: NtfySignalSink заменяется на PostHogSignalSink. Вместо одного
  события more_yes — полный лог: game_open, hub_impression, hub_click,
  teaser_click, first_action, help_open, level_start, level_win,
  level_fail, retry, level_5_complete, rating_submit, comment_submit,
  session_2, return_d1, return_d7. К каждому событию: game_id,
  anonymous_user_id, session_id, timestamp, level, source, version.
- Структура: shell общий в корне репозитория play, в папках отдельных
  игр — только mechanic (выбрано ради простоты поддержки, а не строгого
  соответствия принципу "template is copied, not inherited").

## 2026-09-16 — Экран после 5-го уровня: MoreScreen → попап оценки

**Решение:** MoreScreen (было: да/нет "Ещё?") заменён на попап оценки.
- Звёзды 1–5 — обязательны, кнопка "к уровням" задизейблена, пока не
  выбрана хотя бы одна звезда.
- Поле комментария — опционально.
- Кнопка "к уровням" одновременно сабмит и возврат в LevelSelect;
  уровни можно перепроходить повторно.
- Событие more_yes убрано полностью.
- Событие rating_submit (значение 1–5) летит в PostHog всегда при клике
  на кнопку.
- Событие comment_submit летит в PostHog только если поле комментария
  не пустое в момент клика (сам текст в PostHog не пишется — см. ниже).

## 2026-09-16 — Сбор комментариев из попапа оценки

**Решение:** текст комментария из попапа оценки отправляется на email
через Web3Forms — без бэкенда, без serverless-функции. Клиент шлёт POST
напрямую на api.web3forms.com с access_key.

**Что летит в письме:** название игры (game_id), anonymous_user_id,
текст комментария.

**Получатель:** stas@hrytsko.com

**Почему так:** самое простое решение из доступных — не нужен ни
Supabase, ни своя serverless-функция с почтовым провайдером. Бесплатный
тир Web3Forms — 250 писем/месяц, для фазы 1 (одна игра в день) с запасом;
в фазе 2 на популярной игре может понадобиться апгрейд — решаем по факту,
не сейчас.

**Что отдельно:** число звёзд (1–5) параллельно летит в PostHog как
событие `rating_submit` — комментарии по почте эту метрику не заменяют.
