# data/

> **Шаг 8, первая половина — цифры.** Вход — опубликованная игра.
> Дальше: `../results/`. Путь целиком — `../docs/PLAY.md`.

Выгрузка цифр из PostHog, один файл на игру: `data/<slug>.json`. Пишет
скрипт, руками не правится.

Окно измерения — **месяц с даты релиза**. Выгрузка делается по его окончании,
а при желании и раньше, промежуточно: файл перезаписывается целиком, поле
`pulledAt` говорит, на какой момент снята картинка.

```json
{
  "slug": "arrow-flip",
  "releasedAt": "2026-10-05",
  "pulledAt": "2026-11-05T20:00:00Z",
  "windowDays": 30,
  "opened": 214,
  "started": 148,
  "byLevel": { "1": 148, "2": 112, "3": 81, "4": 59, "5": 41 },
  "completed": 41,
  "failed": 96,
  "retried": 67,
  "returnedLater": 12,
  "ratings": { "1": 0, "2": 2, "3": 7, "4": 14, "5": 9 },
  "comments": 5,
  "bySource": { "telegram": 88, "tiktok": 61, "x": 34 }
}
```

`completed` — дошли до конца пятого уровня. `returnedLater` — вернулись
сыграть в эту же игру в другой день; на маленькой выборке это честнее
рейтинга, потому что возврат ничего не стоит подделать самому себе.

**Нужен персональный API-ключ PostHog, а не проектный токен из
`analytics-config.js`.** Проектный токен умеет только писать. Ключ на чтение
в репозиторий не попадает — только переменная окружения.
