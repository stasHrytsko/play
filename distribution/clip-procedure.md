# Процедура ролика

Строка 10 конвейера. Десять секунд экрана в 9:16, без монтажа, повторяемо,
за десять минут. Один раз настраивается, дальше — шесть шагов вечером.

Итог дня: файл `clips/NN.mp4`, где `NN` — номер дня с ведущим нулём. Именно
этот путь стоит в колонке `Media` сгенерированного CSV, так что имя файла —
не вкусовщина, а контракт с планировщиком.

## Настройка один раз

### 1. Устройство в DevTools

Chrome → DevTools → Toggle device toolbar (Cmd+Shift+M) → Edit → Add custom
device:

- Name: `PoP 9:16`
- Width: `396`
- Height: `704`
- Device pixel ratio: `2`
- User agent type: Mobile

Почему не 390×844, как в плане: 390×844 — это пропорция 9:19.5, а не 9:16.
Ролик придётся или кропать (это монтаж, которого мы не хотим), или отдавать
платформе на автокроп, и она сама решит, что обрезать. 396×704 — ровно 16/9,
и при DPR 2 запись выходит 792×1408, то есть выше минимума в 720p у всех
восьми каналов.

### 2. Чистый кадр

В device mode:

- закрыть панель DevTools в отдельное окно (Cmd+Shift+D переключает док) или
  свернуть её, чтобы в кадре не осталось инспектора;
- убрать линейки: DevTools → ⋮ → Settings → Preferences → снять «Show rulers
  on hover»;
- масштаб страницы 100%, иначе размер записи поедет.

### 3. Область записи

Cmd+Shift+5 → Record Selected Portion. Один раз выделить область ровно по
краю телефонного вьюпорта. macOS запоминает последнюю рамку выделения, и в
следующие разы её не надо выставлять заново — достаточно проверить, что она
всё ещё совпадает с вьюпортом.

Там же в меню Options: Microphone → None, Show Mouse Clicks → выключить
(кружки от кликов в ролике выглядят как баг), Save to → папка `clips`.

## Каждый вечер, шесть шагов

1. Открыть игру дня на `play.hrytsko.com/<slug>/` в device mode `PoP 9:16`.
2. Пройти до состояния, с которого хочется начать ролик. Кадр должен
   открываться уже в интересной позиции — первые полсекунды решают, досмотрят
   или пролистнут.
3. Cmd+Shift+5 → Record (рамка уже стоит с прошлого раза) → Record.
4. Сыграть **один payoff-момент**: то самое, что в спеке описано в разделе 7
   как момент расплаты. Не туториал, не выбор уровня — сразу действие и
   последствие.
5. Стоп на десятой секунде. Кнопка стопа в меню-баре, либо Cmd+Ctrl+Esc.
6. Переименовать в `clips/NN.mp4` (см. ниже про формат) и проверить, что файл
   открывается в QuickTime.

Десять секунд — это потолок, а не цель. Восемь лучше двенадцати.

## Формат файла

Cmd+Shift+5 сохраняет `.mov` (H.264), а не `.mp4`. TikTok, Shorts, Instagram,
X и Threads `.mov` принимают, так что можно просто переименовать расширение в
CSV и не конвертировать. Если какой-то канал упрётся — одна строка:

```sh
ffmpeg -i clips/NN.mov -c:v libx264 -crf 20 -pix_fmt yuv420p -an clips/NN.mp4
```

`-an` убирает звуковую дорожку: звука в роликах нет по замыслу, а пустая
дорожка иногда ломает автопостинг.

Если решишь не конвертировать вообще — поменяй расширение в одной строке
`build-posts.mjs` (константа в блоке, где собирается поле `Media`) и
перегенерируй CSV.

## Запасной способ: запись через Playwright

Если ручная запись начнёт съедать больше десяти минут, в репозитории уже
есть всё для скриптовой: Playwright настроен, Chromium предустановлен.

```js
const context = await browser.newContext({
  viewport: { width: 396, height: 704 },
  deviceScaleFactor: 2,
  recordVideo: { dir: 'clips/', size: { width: 792, height: 1408 } }
});
```

Плюс: абсолютно одинаковый кадр каждый день, ноль ручных действий, ролик
собирается тем же скриптом, что гоняет e2e. Минус: играет бот, и это видно —
движения слишком ровные, пауз «человек думает» нет. Для механик, где payoff
в один тап (04, 14, 25), разницы никакой. Для механик, где важно колебание
перед решением (24, 29, 35), ручная запись выразительнее.

Playwright пишет `.webm`. Конвертация — та же строка ffmpeg, только на входе
`.webm`.

## Чего в ролике нет

Это не стилистика, а правило эксперимента — иначе ролики перестанут быть
сравнимыми между собой:

- нет монтажа, склеек и ускорений;
- нет звука и музыки;
- нет титров, стрелок, зумов и подписей поверх кадра;
- нет курсора и кружков от кликов;
- нет экрана выбора уровней и туториала — только игра.
