# 1. Паспорт концепта

- Название: Подвал
- **Правило одной фразой:** Бери верхнюю фигуру из одной из трёх стопок и укладывай её на поле.
- Глагол: укладка
- Давление: блокировка доступа
- Твист: нет
- **Целевая эмоция:** облегчение от того, что нужная фигура наконец открылась в стопке
- **Уровни:** генерируется
- **Солвер:** не нужен
- Оценка: 26/30 — чит 5, мот 5, давл 3, payoff 3, произв 5, рынок 5

# 2. Цель и условия

Правила уровня — текст в кнопке «?»:

Перед тобой три стопки фигур. Видна только верхняя фигура каждой стопки. Перетащи одну из них на поле. После размещения под ней откроется следующая. Полностью заполненная строка или колонка очищается. Разбери все три стопки, не заперев поле.

- Условие ПОБЕДЫ: все три стопки пусты после размещения последней фигуры.
- Условие ПОРАЖЕНИЯ: хотя бы одна стопка не пуста, но ни одна из трёх доступных верхних фигур не имеет ни одного легального размещения на поле.
- Runtime RNG нет. Фигуры в стопках и их порядок зафиксированы уровнем.

# 3. Правила

1. На старте загружается пустое или частично занятое поле и три фиксированные стопки фигур.
2. Игрок видит только верхнюю фигуру каждой непустой стопки.
3. Игрок перетаскивает верхнюю фигуру выбранной стопки на клетки поля.
4. Фигура может быть размещена только целиком внутри поля и только на свободных клетках.
5. Невалидный drop возвращает фигуру в стопку и не считается ходом.
6. Валидный drop фиксирует фигуру на поле и снимает её с вершины стопки.
7. После размещения одновременно очищаются все полностью заполненные строки и колонки.
8. После очистки открывается следующая фигура в использованной стопке.
9. Фигуры нельзя вращать, отражать или перемещать после размещения.
10. После каждого разрешённого хода движок проверяет победу по п.2.
11. Если стопки ещё не пусты, движок проверяет наличие хотя бы одного легального размещения среди доступных верхних фигур.
12. Если легального размещения нет, фиксируется поражение по п.2.

# 4. Состояние уровня

```ts
type Shape = {
  id: string;
  cells: { x: number; y: number }[];
};

type GameState = {
  board: (string | null)[][];
  stacks: Shape[][];
  moves: number;
  status: 'playing' | 'won' | 'failed';
};
```

В каждой `stacks[i]` последний элемент массива считается верхней фигурой.

# 5. Ввод

```ts
{
  type: 'drag';
  targetId: string;
  dropCell: { x: number; y: number };
}
```

Один игровой жест — drag верхней фигуры из стопки на поле. `dropCell` задаёт якорную клетку фигуры.

# 6. Контент уровня

Пример `levels.json`:

```json
{
  "id": 1,
  "grid": { "w": 8, "h": 8 },
  "prefill": [],
  "stacks": [
    ["shape_l3", "shape_dot", "shape_bar2"],
    ["shape_square4", "shape_dot"],
    ["shape_bar3", "shape_l3"]
  ]
}
```

Список фигур берётся из фиксированной библиотеки polyomino. Генератор строит стопки из заранее валидной последовательности размещений и сохраняет результат. Runtime RNG нет.

Кривая по пяти уровням:

1. 3 короткие стопки, простые фигуры 1–3 клетки. Любая верхняя фигура помещается очевидно.
2. Появляются линии очистки; одна стопка специально открывает фигуру, нужную для завершения ряда.
3. Первый настоящий выбор: две фигуры помещаются хорошо сейчас, но только выбор правильной стопки открывает нужную следующую форму.
4. Более плотное стартовое поле; игроку приходится оставлять пространство под ещё скрытые фигуры.
5. Все три стопки влияют друг на друга; минимум три решения должны зависеть от того, какую следующую фигуру откроет текущий выбор.

# 7. Визуал

- Поле: квадратная сетка с мягко отделёнными клетками.
- Под полем: три вертикальные стопки-карточки; видна верхняя фигура и край следующей карточки без раскрытия формы.
- Выбрано: верхняя фигура приподнимается при drag, на поле показывается ghost-placement.
- Выполнено: фигура снапается в клетки; заполненные линии коротко схлопываются.
- Payoff: после placement верхняя карточка стопки уходит, следующая фигура поднимается и раскрывается за один короткий переход.
- Ошибка: невалидная позиция слегка отталкивает фигуру назад; ход не тратится.
- HUD: `Осталось фигур: N`, размеры трёх стопок `N / N / N`.

# 8. Онбординг

1. Здесь три стопки фигур.
2. Брать можно только верхнюю фигуру каждой стопки.
3. Перетащи фигуру на свободные клетки поля.
4. Полная строка или колонка очищается.
5. После хода в стопке откроется следующая фигура.
6. Разбери все стопки, не заперев поле.

Кнопка `?` показывает только правило из п.2.

# 9. Явно ВНЕ рамок

- Без меты, валют, коллекций, заданий, ежедневных бонусов, рекламы, IAP.
- Без runtime RNG.
- Одно давление: блокировка доступа к нижним фигурам.
- Твист отсутствует.
- Без вращения фигур, hold-слота, бустеров, undo и перестановки стопок.
- Скрыта только форма нижних фигур как заранее зафиксированное состояние уровня; количество фигур в стопке видно.
- Без изменений баланса/уровней после публикации, кроме датированного критического бага.

# 10. Метрики и события

Шелл сам логирует общие события эксперимента.

Механика вызывает:

- `first_action` — первый валидный drop фигуры на поле.
- `level_start` — вход на уровень с номером уровня.
- `level_win` — когда все три стопки пусты.
- `level_fail` — когда ни одна доступная верхняя фигура не имеет легального размещения; `reason: 'no_legal_placement'`.
- `retry` — повтор того же уровня после fail.
- `level_5_complete` отдельно не эмитится.

Kill-критерий концепта: если выбор стопки решается жадным правилом «клади фигуру, которая лучше всего подходит прямо сейчас» в 90% проверенных состояний, концепт хоронится.

Онлайн-резерв: читаемость, доходимость до 5 уровня, возврат D1. Если критерий не сработал — концепт не чинится.
