# 1. Паспорт концепта

- Название: Через два хода
- **Правило одной фразой:** Вызывай машины заранее: они въезжают через два хода, и место должно быть свободно.
- Глагол: сдвиг
- Давление: навязанная очередь
- Твист: отложенный эффект
- **Целевая эмоция:** предвкушение — «я сейчас освобожу место ровно к приезду»
- **Уровни:** генерируется
- **Солвер:** не нужен
- Оценка: 26/30 — чит 4, мот 4, давл 4, payoff 4, произв 5, рынок 5

# 2. Цель и условия

Правила уровня — текст в кнопке «?»:

На парковке уже стоят машины. В очереди видна следующая машина и место, куда она должна въехать. Нажми «Вызвать»: она приедет после двух сдвигов других машин. За эти два хода освободи отмеченные клетки. Если в момент приезда хотя бы одна нужная клетка занята — проигрыш.

- Условие ПОБЕДЫ: все машины из фиксированной очереди успешно въехали на парковку.
- Условие ПОРАЖЕНИЯ: таймер вызванной машины дошёл до `0`, а хотя бы одна клетка её заранее показанного места занята другой машиной.
- Runtime RNG нет. Стартовая парковка, очередь приезда, размеры машин и их места въезда заданы уровнем.

# 3. Правила

1. На старте загружается парковочная сетка, стоящие машины и фиксированная очередь прибывающих машин.
2. Игрок видит первую машину очереди и подсвеченные клетки, которые она займёт при въезде.
3. Пока машина не вызвана, таймер приезда отсутствует.
4. Тап по кнопке `Вызвать` планирует текущую машину к приезду через два успешных сдвига и не считается ходом.
5. Пока машина в пути, новую машину вызвать нельзя.
6. Игрок свайпает стоящую машину вдоль её разрешённой оси на одну клетку.
7. Сдвиг выполняется только если целевая клетка свободна и находится внутри парковки.
8. Невалидный свайп ничего не меняет и не считается ходом.
9. Каждый валидный сдвиг уменьшает таймер приезда на `1`, если машина уже вызвана.
10. При таймере `1 → 0` сразу проверяется место въезда.
11. Если все нужные клетки свободны, вызванная машина занимает их, удаляется из очереди, и показывается следующая машина с её местом.
12. Если хотя бы одна нужная клетка занята, фиксируется поражение по п.2.
13. Уже приехавшая машина становится обычной машиной на поле и может двигаться по тем же правилам.
14. Машины не могут пересекаться, поворачиваться или менять размер.
15. Если очередь пуста и последняя вызванная машина успешно въехала, фиксируется победа по п.2.

# 4. Состояние уровня

```ts
type CarState = {
  id: string;
  x: number;
  y: number;
  length: 2 | 3;
  axis: 'h' | 'v';
};

type IncomingCar = {
  id: string;
  length: 2 | 3;
  axis: 'h' | 'v';
  targetCells: { x: number; y: number }[];
};

type GameState = {
  cars: CarState[];
  queue: IncomingCar[];
  pending: IncomingCar | null;
  arrivalIn: 0 | 1 | 2 | null;
  moves: number;
  status: 'playing' | 'won' | 'failed';
};
```

# 5. Ввод

```ts
{ type: 'call' } |
{ type: 'swipe'; targetId: string; dir: 'up' | 'down' | 'left' | 'right' }
```

`call` — вызов видимой машины. `swipe` — попытка сдвинуть существующую машину на одну клетку.

# 6. Контент уровня

Пример `levels.json`:

```json
{
  "id": 1,
  "grid": { "w": 6, "h": 6 },
  "arrivalDelay": 2,
  "cars": [
    { "id": "a", "x": 1, "y": 1, "length": 2, "axis": "h" }
  ],
  "incoming": [
    {
      "id": "i1",
      "length": 2,
      "axis": "v",
      "targetCells": [{ "x": 4, "y": 0 }, { "x": 4, "y": 1 }]
    }
  ]
}
```

Генератор создаёт только уровни, где существует последовательность валидных сдвигов, позволяющая принять всю очередь. Runtime RNG нет.

Кривая по пяти уровням:

1. 1 прибывающая машина. Один очевидный сдвиг освобождает часть места, второй завершает подготовку.
2. 2 прибывающие машины. Игрок впервые повторяет цикл `вызвал → два сдвига → приезд`.
3. 3 прибывающие машины. Первый настоящий выбор: один из двух допустимых сдвигов мешает месту будущего въезда.
4. 4 прибывающие машины. Нужно двигать уже приехавшие машины и учитывать следующее целевое место.
5. 5 прибывающих машин. Минимум два эпизода, где лучший первый сдвиг отличается от лучшего сдвига без двухходовой задержки.

# 7. Визуал

- Поле: компактная парковочная сетка с прямоугольными машинами.
- Место приезда: контур из клеток с иконкой ожидаемой машины.
- Машина в пути: карточка над полем `приедет через 2/1`.
- Выбрано: при начале свайпа машина слегка приподнимается.
- Выполнено: машина снапается в соседнюю клетку.
- Payoff: при `0` ожидаемая машина быстро въезжает в заранее показанный слот; должно быть ясно за секунду, что план сработал.
- Ошибка: если место занято, въезжающая машина останавливается у границы, занятые клетки коротко подчёркиваются, затем fail.
- HUD: `Осталось машин: N`, `Приедет через: 2/1`, preview следующей машины и её места.

# 8. Онбординг

1. Вот следующая машина и место, куда она приедет.
2. Нажми `Вызвать`.
3. Машина въедет после двух твоих сдвигов.
4. За эти два хода освободи отмеченные клетки.
5. Если место занято в момент приезда — проигрыш.

Кнопка `?` показывает только правило из п.2.

# 9. Явно ВНЕ рамок

- Без меты, валют, коллекций, заданий, ежедневных бонусов, рекламы, IAP.
- Без runtime RNG.
- Одно давление: навязанная очередь.
- Один твист: отложенный эффект в два хода.
- Без таймера реального времени, ускорения/замедления приезда, отмены вызова, бустеров и undo.
- Машины не поворачиваются и не меняют размер.
- Без изменений баланса/уровней после публикации, кроме датированного критического бага.

# 10. Метрики и события

Шелл сам логирует общие события эксперимента.

Механика вызывает:

- `first_action` — первый тап `Вызвать`.
- `level_start` — при входе на каждый уровень с номером уровня.
- `level_win` — когда вся очередь успешно принята.
- `level_fail` — если место въезда занято при `arrivalIn === 0`; `reason: 'arrival_blocked'`.
- `retry` — повтор того же уровня после fail.
- `level_5_complete` отдельно не эмитится.

Kill-критерий концепта: задержка должна заставлять изменить план минимум один раз за уровень; если можно играть так же, как без задержки, концепт хоронится.

Онлайн-резерв: читаемость, доходимость до 5 уровня, возврат D1. Если критерий не сработал — концепт не чинится.
