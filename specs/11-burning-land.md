# 1. Паспорт концепта

- Название: Burning Land
- **Правило одной фразой:** Каждый ход ставь стену, потом огонь расширится; спаси нужную ценность.
- Глагол: укладка
- Давление: растущая угроза
- Твист: нет
- **Целевая эмоция:** паника — «я не успеваю спасти всё, надо решить, что защищать сейчас»
- **Уровни:** генерируется
- **Солвер:** нужен
- Оценка: 26/30 — чит 5, мот 5, давл 5, payoff 4, произв 3, рынок 4

Дополнительно:
- Семейство: Block
- Отличие от аналога: Block Blast — размещение фигур используется для триажа пространства, а не для очистки линий.
- TREND: да
- Kill-критерий: если более чем в 30% валидных уровней итог в основном определяется стартовым распространением огня, а не постановками игрока, концепт хоронится.

# 2. Цель и условия

Правила уровня — текст для кнопки `?`:

Каждый ход поставь текущую фигуру-стену на свободные клетки. После этого огонь одновременно переходит на все соседние свободные клетки вверх, вниз, влево и вправо. Стены огонь не пропускают. Ценные клетки, которых коснулся огонь, потеряны. Запри огонь стенами и сохрани не меньше указанной ценности.

- Условие ПОБЕДЫ: огонь полностью заперт — ни у одной горящей клетки нет соседней свободной клетки — и сумма ценности всех не сгоревших ценных клеток `savedValue >= targetSavedValue`.
- Условие ПОРАЖЕНИЯ есть. Оно наступает, если выполнено хотя бы одно условие:
  1. после распространения огня максимальная возможная сохраняемая ценность стала меньше `targetSavedValue`;
  2. огонь ещё не заперт, но текущую фигуру-стену нельзя легально разместить ни в одной позиции.
- Если огонь заперт, но `savedValue < targetSavedValue`, фиксируется поражение.
- Runtime RNG отсутствует. Стартовый огонь, ценные клетки, их ценность, препятствия и вся очередь фигур заранее зафиксированы уровнем.

# 3. Правила

1. На старте уровня движок загружает сетку, стартовые горящие клетки, ценные клетки, препятствия, фиксированную очередь фигур и `targetSavedValue`.
2. На поле одновременно существуют клетки пяти типов: свободная, горящая, стена, постоянное препятствие, ценная.
3. Ценная клетка остаётся проходимой для огня, пока не защищена стеной или пока огонь не будет заперт раньше неё.
4. Игрок видит текущую фигуру-стену и две следующие фигуры очереди.
5. Игрок перетаскивает текущую фигуру на поле.
6. Фигура может быть размещена только целиком внутри сетки.
7. Все клетки фигуры должны быть свободны и не должны содержать огонь, препятствие, стену или ценную клетку.
8. Фигуры нельзя вращать или отражать.
9. Невалидный drop возвращает фигуру в исходную позицию и не считается ходом.
10. Валидный drop превращает занятые фигурой клетки в стены и считается одним ходом.
11. После валидного размещения текущая фигура удаляется из очереди, а следующая становится текущей.
12. Сразу после размещения огонь делает один такт распространения.
13. За один такт каждая горящая клетка одновременно пытается распространиться на все четыре ортогонально соседние клетки.
14. Огонь не распространяется по диагонали.
15. Огонь не проходит через стены и постоянные препятствия.
16. Огонь распространяется в свободную клетку.
17. Если свободная клетка одновременно достижима из нескольких горящих клеток, она всё равно загорается один раз.
18. Если огонь входит в ценную клетку, эта клетка становится горящей, а её ценность считается потерянной до конца попытки.
19. Уже горящие клетки остаются горящими до конца уровня.
20. После распространения движок вычисляет `savedValue` как сумму ценности всех ещё не сгоревших ценных клеток.
21. После распространения движок проверяет, есть ли хотя бы одна свободная или ценная клетка, ортогонально соседняя с любой горящей клеткой и доступная огню.
22. Если таких клеток нет, огонь считается полностью запертым.
23. Если огонь заперт и `savedValue >= targetSavedValue`, фиксируется победа по п.2.
24. Если огонь заперт и `savedValue < targetSavedValue`, фиксируется поражение по п.2.
25. Если огонь не заперт, движок вычисляет `maxPossibleSavedValue` как сумму ценности всех ещё не сгоревших ценных клеток.
26. Если `maxPossibleSavedValue < targetSavedValue`, фиксируется поражение по п.2.
27. Если победы или поражения нет, начинается следующий ход.
28. Перед следующим ходом движок проверяет, существует ли хотя бы одно легальное размещение текущей фигуры.
29. Если легального размещения нет, а огонь не заперт, фиксируется поражение по п.2.
30. Игрок не может пропустить ход, удалить стену или изменить порядок фигур.

# 4. Состояние уровня

```ts
type CellKind = 'free' | 'fire' | 'wall' | 'blocked' | 'valuable';

type WallShape = {
  id: string;
  cells: { x: number; y: number }[];
};

type GameState = {
  fireCells: string[];
  wallCells: string[];
  burnedValuableCells: string[];
  queue: WallShape[];
  moves: number;
  savedValue: number;
  targetSavedValue: number;
  status: 'playing' | 'won' | 'failed';
};
```

Ценность клеток и постоянные препятствия хранятся в неизменяемом описании уровня.

# 5. Ввод

Один игровой жест — drag текущей фигуры на поле:

```ts
{
  type: 'drag';
  targetId: string;
  dropCell: { x: number; y: number };
}
```

`targetId` всегда относится к текущей фигуре очереди. `dropCell` задаёт её якорную клетку.

# 6. Контент уровня

Пример `levels.json`:

```json
{
  "id": 1,
  "grid": { "w": 8, "h": 8 },
  "targetSavedValue": 7,
  "fire": [
    { "x": 3, "y": 3 }
  ],
  "valuable": [
    { "x": 1, "y": 1, "value": 2 },
    { "x": 6, "y": 2, "value": 3 },
    { "x": 6, "y": 6, "value": 4 }
  ],
  "blocked": [],
  "wallQueue": [
    "bar2_h",
    "l3",
    "bar2_v",
    "dot",
    "bar3_h"
  ]
}
```

Правила контента:

- Библиотека стен состоит из фиксированных polyomino размером 1–3 клетки.
- Поворот фигур игроком запрещён; ориентация является частью `shapeId`.
- Текущая фигура и две следующие всегда видны.
- Очередь полностью зафиксирована до старта уровня.
- Runtime RNG отсутствует.
- Solver обязан подтвердить хотя бы один маршрут, который запирает огонь и сохраняет `targetSavedValue`.
- Solver также проверяет kill-критерий: разные легальные постановки должны реально менять итог хотя бы в ключевых состояниях уровня.

Кривая по пяти уровням:

1. **Обучение стене.** Один очаг, простое поле, фигуры из 1–2 клеток. Одной очевидной стеной игрок меняет фронт огня и затем запирает его.
2. **Обучение ценности.** Несколько ценных клеток с разной стоимостью. Спасти всё нельзя, но `targetSavedValue` достигается двумя понятными постановками.
3. **Первый настоящий выбор.** Два направления распространения и минимум две разумные позиции стены. Одна спасает ближайшую дешёвую клетку, другая — более дорогую область дальше.
4. **Давление.** Несколько очагов или один разветвлённый фронт, 4–5 ценных зон и более тесное поле. Игрок должен жертвовать частью территории, чтобы сохранить целевую ценность.
5. **Проверка концепта.** Несколько последовательных решений триажа. Минимум три хода должны иметь по две легальные постановки с заметно разным будущим фронтом огня. Без планирования на 2–3 такта уровень не должен проходиться стабильно.

# 7. Визуал

- Поле: квадратная сетка с хорошо читаемыми клетками.
- Огонь: заполненная клетка с короткой живой анимацией внутри; граница фронта визуально отличается от старых горящих клеток.
- Ценная клетка: отдельный символ и число ценности `1–3`; цвет берётся из `tokens.css`.
- Стена: плотные блоки, визуально перекрывающие клетки полностью.
- Текущая фигура: крупно под полем; следующие две — уменьшенным preview.
- Выбрано: при drag фигура приподнимается, на сетке показывается ghost-placement.
- Валидная позиция: ghost точно совпадает с будущими клетками стены.
- Ошибка: невалидный drop коротко отталкивает фигуру назад; ход не тратится.
- После каждого валидного placement новая стена снапается, затем с короткой паузой огонь одним импульсом захватывает все новые клетки одновременно.
- Потеря ценности: если огонь входит в ценную клетку, её маркер быстро гаснет, а счётчик `Спасено` обновляется.
- Payoff: при полном окружении фронт огня упирается в стену со всех сторон и перестаёт расширяться; за секунду должно быть понятно, что пожар остановлен.
- HUD: `Спасено: X / target`, `Ход: N`, текущая фигура + preview двух следующих.

# 8. Онбординг

1. Поставь фигуру-стену на свободные клетки.
2. После каждого твоего хода огонь расширяется на соседние клетки.
3. Стены полностью останавливают огонь.
4. Ценные клетки сгорают, если огонь до них доберётся.
5. Запри пожар и сохрани минимум указанную ценность.
6. Следующие две фигуры видны заранее.

Кнопка `?` показывает только правило из п.2 и не повторяет пошаговое обучение.

# 9. Явно ВНЕ рамок

- Без меты, валют, коллекций, заданий, ежедневных бонусов, рекламы, IAP.
- Без runtime RNG.
- Одно давление: растущая угроза огня.
- Твист отсутствует.
- Без таймера реального времени.
- Без очистки линий.
- Без воды, тушения, пожарных, бустеров и активных способностей.
- Без удаления или перемещения уже поставленных стен.
- Без вращения фигур игроком.
- Без пропуска хода.
- Без изменений баланса/уровней после публикации, кроме датированного критического бага.

# 10. Метрики и события

Шелл самостоятельно логирует `game_open`, `hub_impression`, `hub_click`, `teaser_click`, `help_open`, `more_yes`, `session_2`, `return_d1`, `return_d7` и общие поля.

Механика вызывает:

- `first_action` — первый валидный drop текущей фигуры-стены на поле.
- `level_start` — при входе на каждый уровень, с номером уровня.
- `level_win` — когда огонь полностью заперт и `savedValue >= targetSavedValue`.
- `level_fail` — при любом условии поражения из п.2; `reason: 'target_unreachable' | 'no_legal_placement' | 'contained_below_target'`.
- `retry` — повтор того же уровня после `level_fail`.
- `level_5_complete` отдельно не эмитится.

Kill-критерий концепта: если доля валидных уровней, где итог практически не зависит от постановок игрока и определяется самим фронтом огня, превышает 30%, концепт хоронится.

Онлайн-резерв: читаемость, доходимость до 5 уровня, возврат D1. Если критерий не сработал — концепт не чинится.
