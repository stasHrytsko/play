# dashboard/

Доска конвейера на экран. Отдельный статический проект — деплоится на Vercel
из этой папки, независимо от хаба.

```
dashboard/
  index.html     страница, без зависимостей и без сборки
  status.json    данные ← пишет pipeline.mjs
  vercel.json    статика, без build-команды
  favicon.svg
```

## Обновить

**Правило: доска не отстаёт от репозитория** (`CLAUDE.md`, правило №1). Любое
движение по конвейеру едет вместе с обновлённым `status.json`, в том же
коммите.

```sh
git config core.hooksPath .githooks   # один раз на машине — дальше само
node pipeline.mjs --write             # вручную, если хук не включён
node pipeline.mjs --check             # упасть, если снимок отстал
```

Второе стоит в CI. Причина простая: доска, которая показывает вчерашнее
состояние и при этом выглядит свежей, — худший вид поломки. Сверяется только
то, что зависит от файлов; дата и обратный отсчёт до старта меняются сами, их
сверять нельзя.

Страница дополнительно подсвечивает снимок старше трёх дней — на случай, если
экран висит на старом деплое.

## Локально

```sh
cd dashboard && python3 -m http.server 8077
```

Файлом (`file://`) не откроется: страница читает `status.json` через `fetch`.

## Деплой на Vercel

Новый проект из того же репозитория:

- **Root Directory:** `dashboard`
- **Framework Preset:** Other
- **Build Command:** пусто
- **Output Directory:** пусто (отдаётся сама папка)

Сборки нет — `status.json` лежит в репозитории и приезжает с коммитом. То
есть доска ровно настолько свежа, насколько свеж последний пуш, и это
правильно: состояние системы и есть содержимое репозитория.

**Закрой доступ.** Settings → Deployment Protection → Vercel Authentication
или пароль. Доска показывает внутреннюю кухню: какие идеи отклонены, что на
доработке, какие игры выйдут в какие дни.

Отдельное предупреждение: корень репозитория отдаётся хабом
`play.hrytsko.com` как есть, поэтому `play.hrytsko.com/dashboard/` тоже
откроется. Если это мешает — добавь в `vercel.json` проекта хаба правило,
отдающее 404 на `/dashboard/*`. Сам репозиторий публичный, так что секретом
это в любом случае не было.

## Что на странице

**Ждёт тебя** — единственная крупная цифра и список. Три из четырёх ворот —
твоё решение, и ровно они теряются первыми. Остальное на странице отвечает на
вопрос «как дела», этот блок — на вопрос «за что браться».

**Всего** — плитки со счётчиками.

**Дошли хотя бы до стадии** — воронка. Накопленный счёт, а не доля от целого:
иначе ранние стадии выглядели бы достижением. Порядковая рампа в одной
тональности, проверена валидатором в светлой и тёмной моде.

**Таблицы** — расписание тридцати дней и концепты без назначенного дня.

Стадии нигде не хранятся — считаются из того, какие файлы есть. Поэтому доску
нельзя забыть обновить: обновлять в ней нечего, только пересчитать.
