# dashboard/

Доска конвейера на экран. Отдельный статический проект — деплоится на Vercel
из этой папки, независимо от хаба.

```
dashboard/
  index.html     страница, без зависимостей и без сборки
  status.json    данные ← пишет pipeline.mjs
  vercel.json    статика, без build-команды
  favicon.svg
```

## Обновлять не нужно

**Правило №1** (`CLAUDE.md`): доска всегда показывает текущее состояние. Для
этого не нужно ничего делать, и это сознательно — правило, которое держится
на памяти, не правило.

- `status.json` **не коммитится** (он в `.gitignore`). Vercel собирает его на
  каждом пуше командой `node pipeline.mjs --write`. Забыть обновить файл,
  которого нет в репозитории, невозможно.
- Стадии нигде не хранятся — считаются из того, какие файлы есть. Двигая
  конвейер, ты уже обновил доску.
- Всё, что зависит от даты, страница пересчитывает **в браузере**: обратный
  отсчёт до старта, «идёт 12/30 дн.», «месяц вышел», «снять цифры». Поэтому
  вкладка, висящая на экране неделю, не врёт и без нового деплоя. Пороги
  (месяц, тридцать прохождений) приезжают в данных из `pipeline.mjs` — чтобы
  оставаться записанными в одном месте.

Пуш обновляет то, что зависит от файлов; открытая вкладка — то, что зависит
от даты.

## Локально

```sh
cd dashboard && python3 -m http.server 8077
```

Файлом (`file://`) не откроется: страница читает `status.json` через `fetch`.

## Деплой на Vercel

Новый проект из того же репозитория. **Root Directory оставить корнем**, а не
ставить `dashboard` — генератору нужен весь репозиторий, он читает `specs/`,
`ideas/`, `games.json`, `app/games/`:

| Настройка | Значение |
|---|---|
| Root Directory | `./` (корень) |
| Framework Preset | Other |
| Build Command | `node pipeline.mjs --write` |
| Output Directory | `dashboard` |
| Install Command | пусто (в корне нет `package.json`) |

Настраивается в интерфейсе Vercel, а не файлом: `vercel.json` в корне читали
бы **оба** проекта, и хаб начал бы отдавать доску вместо себя.

Проект хаба при этом не трогается — он как был отдаёт корень без сборки.

**Закрой доступ.** Settings → Deployment Protection → Vercel Authentication
или пароль. Доска показывает внутреннюю кухню: какие идеи отклонены, что на
доработке, какие игры выйдут в какие дни.

Побочно помогает то, что `status.json` не коммитится: по адресу
`play.hrytsko.com/dashboard/` страница откроется, но данных там нет — хаб
отдаёт корень без сборки, и файла в репозитории просто не существует. Видно
будет сообщение об ошибке, а не состояние проекта. Полностью убрать этот
адрес можно правилом на 404 в `vercel.json` проекта хаба.

## Что на странице

**Ждёт тебя** — единственная крупная цифра и список. Три из четырёх ворот —
твоё решение, и ровно они теряются первыми. Остальное на странице отвечает на
вопрос «как дела», этот блок — на вопрос «за что браться».

**Всего** — плитки со счётчиками.

**Дошли хотя бы до стадии** — воронка. Накопленный счёт, а не доля от целого:
иначе ранние стадии выглядели бы достижением. Порядковая рампа в одной
тональности, проверена валидатором в светлой и тёмной моде.

**Таблицы** — расписание тридцати дней и концепты без назначенного дня.

Стадии нигде не хранятся — считаются из того, какие файлы есть. Поэтому доску
нельзя забыть обновить: обновлять в ней нечего, только пересчитать.
